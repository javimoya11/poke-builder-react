# Poké Builder - Prueba de React con Pokémon
### Descripción
¡Crea tu equipo Pokémon! Con esta pequeña aplicación de prueba que usa la [PokeAPI](https://pokeapi.co) podrás crear tu equipo propio equipo Pokémon. (En desarrollo)

### Ejecución del proyecto
```
Desarrollo - npm run dev
Build - npm run build
Lint - npm run lint

```
